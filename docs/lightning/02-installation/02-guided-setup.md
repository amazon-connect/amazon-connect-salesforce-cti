title: Guided Setup (Retired)
---

Guided Setup is retired. Do not use the Guided Setup wizard.

To set up the CTI Adapter, follow the manual setup guides in this order:

1. [Managed Package Manual Setup](/docs/lightning/installation/03-managed-package-manual-setup)
2. [Salesforce Lambdas Manual Setup](/docs/lightning/installation/04-salesforce-lambdas-manual-setup)

If you set up the CTI Adapter with Guided Setup before, remove the resources that you created for it. See [Appendix H: Removing the Guided Setup Resources](/docs/lightning/appendices/appendix-h-restricting-sfexecuteawsservice/01-restricting-sfexecuteawsservice).
